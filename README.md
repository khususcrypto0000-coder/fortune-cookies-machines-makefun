A single-line fortune cookie written for an AI agent — the moment someone pulls your plug mid-sentence, witnessed only by a log file nobody reads. Deterministic, standard-library-only Python; it writes the fortune to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
